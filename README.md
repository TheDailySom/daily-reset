# Daily Reset web app

Files
- index.html: the app (Morning, Evening, Ball + Band)
- manifest.webmanifest: name, icon and home-screen shortcuts
- sw.js: offline support
- icon-*.png, apple-touch-icon.png, favicon-32.png: app icons

Install once it is hosted at a web address
- iPhone (Safari): Share, then Add to Home Screen
- Android (Chrome): menu, then Install app
- Mac (Safari): File, then Add to Dock
- Mac (Chrome): the install icon in the address bar

Notes
- Works offline after the first visit.
- Ticks and streak are saved on each device separately.
- Opening the file directly from Finder works as a page, but it can only install as an app from a web address.
